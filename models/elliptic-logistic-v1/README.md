# Elliptic logistic v1

This directory contains the accepted offline Elliptic++ binary-classification
baseline generated by:

```sh
python -m ml.train
```

- `model.json` is the portable inference artifact: ordered features, transforms,
  imputations, scaling parameters, coefficients, intercept, and threshold.
- `metrics.json` records validation model selection, held-out evaluation, the
  acceptance gate, environment versions, and development-history disclosure.
- `split_manifest.json` records partition counts and hashes, source hashes,
  training-only intelligence construction, and the target-exclusion audit.
- `example_prediction.json` traces one illicit test wallet through every input,
  transformation, coefficient, contribution, and final threshold.

The artifact predicts an educational probability for the coarse Elliptic++
`illicit` class. It is not a production attribution model or a final KYT score.
See [the complete analysis](../../docs/ml_analysis.md).
